# Law-os

## What this is
An operator-based legal execution architecture that models how
facts become judgments and how judgments become enforceable.

## Core operators
A / L / W / USE / USAGE / Z

## Two pipelines
- Path 1: Coercive Action
- Path 2: Adjudication & Enforcement

## Key modules
- Public Data Injection Module (PDIM)
- Plausibility Engine (L)
- Coercive Legitimacy Engine (Z1)
