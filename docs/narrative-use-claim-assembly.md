Narrative Use Claim Assembly Protocol (Plausibility → Survive → Evaluate)

Overview

This document defines a structured protocol for assembling narrative-use claims within the Law-OS architecture.

It translates:

facts → narrative → use → value → misalignment

into:

pleading-ready allegations that survive plausibility (L)
and advance to evaluation (Z₂ / Z₃)

This protocol is anchored in:
	•	PDIM (public data)
	•	narrative use
	•	plausibility (12(b)(6))
	•	operator grammar

⸻

I. Core Principle

Claims do not begin at liability.

They begin at plausibility.

Therefore:

the objective is not to prove the case

the objective is to survive L


⸻

II. Canonical Flow

R (recorded facts)
    ↓
PDIM (public data injection)
    ↓
USE_reasoning_plausibility
    ↓
L (claim survives 12(b)(6))
    ↓
Z₂ / Z₃ (evaluation)


⸻

III. Structural Goal

maximize plausibility density at L

This is achieved by:
	•	increasing factual specificity
	•	using public data
	•	establishing clear USE events
	•	linking USE to value

⸻

IV. Claim Assembly Sequence

Step 1 — Identify Narrative (N)

Define the narrative being used.

This must be specific, identifiable, and externally recognizable.

Examples:
	•	historical harm
	•	community identity
	•	institutional mission
	•	public-facing story

⸻

Step 2 — Identify Actor (A)

Define who is using the narrative.

Must be:
	•	a state actor OR
	•	a commercial/institutional actor

⸻

Step 3 — Establish USE (Critical Step)

Allege that A USED N.

This must be:
	•	concrete
	•	observable
	•	tied to action

Examples:
	•	secured funding
	•	justified policy
	•	launched program
	•	issued public messaging

No USE → no claim


⸻

Step 4 — Inject Public Data (PDIM)

Support USE with publicly available facts.

Sources:
	•	press releases
	•	grant records
	•	legislative materials
	•	official statements
	•	public events

This step stabilizes L


⸻

Step 5 — Identify Value (V)

Allege that A received value as a result of USE.

Types of value:
	•	financial (funding, revenue)
	•	institutional (authority, expansion)
	•	reputational (credibility, legitimacy)

⸻

Step 6 — Identify Distribution

Allege where the value went.

This must be:
	•	specific
	•	traceable
	•	connected to A

⸻

Step 7 — Establish Misalignment

Allege that:

USE of N
≠
distribution of V

This is the core structure:

value was generated from N
but not allocated consistently with that use


⸻

Step 8 — Frame the Claim

Convert structure into allegation:

A used N to generate V,
and failed to allocate V in alignment with that use.


⸻

V. Paragraph Construction Template

Each allegation paragraph should follow:

1. Actor (A)
2. Action (USE)
3. Mechanism (how USE occurred)
4. Result (value generated)
5. Supporting fact (public data)

Example structure:

Defendant A publicly invoked [Narrative N]
through [specific action],
including [public source].

As a result, A obtained [Value V],
including [specific benefit].

These facts are reflected in [public record].


⸻

VI. Plausibility Density Rule

More facts per inference = higher survivability

So:

each inference must be supported
by at least one observable fact


⸻

VII. What to Avoid

1. Pure Conclusions

“A acted unfairly”

→ insufficient

⸻

2. Narrative Without USE

mentioning a narrative without operational use

→ no claim

⸻

3. Value Without Causal Link

value must be tied to USE


⸻

VIII. Zb / Za Positioning

At L (Plausibility Stage)

Zb dominates:

- are facts sufficient?
- is USE observable?
- is inference reasonable?


⸻

At Z₂ / Z₃ (Evaluation)

Za becomes central:

- was value allocation aligned?
- was outcome fair/proportional?


⸻

IX. Litigation Strategy Insight

win L first

then argue Z

Meaning:

survive dismissal before arguing fairness


⸻

X. System Mapping

Narrative (N)
    ↓
USE (A uses N)
    ↓
Public Data (PDIM)
    ↓
L (plausibility survives)
    ↓
Z₂ (liability coherence)
    ↓
Z₃ (outcome evaluation)


⸻

XI. Minimal Viable Claim (MVC)

A claim survives if it establishes:

(1) identifiable narrative
(2) observable USE
(3) resulting value
(4) plausible misalignment


⸻

XII. Core Structural Insight

Claims fail not because they are wrong,
but because they are under-specified at L.


⸻

XIII. Final Compression

Use public facts to show:

USE → value → misalignment


⸻

One-Line Definition

A narrative-use claim is a structured allegation that converts public facts into a plausible account of use, value generation, and misalignment sufficient to survive dismissal.
