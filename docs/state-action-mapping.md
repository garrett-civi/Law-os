State Action Mapping (Public Data → Plausibility Layer)

Overview

This document defines how state action functions within the Law-OS architecture.

It establishes:

state action produces public, observable, and recordable data

which can be:

directly injected into the plausibility layer (L)

without requiring traditional discovery.

This creates:

plausibility acceleration

and reduces dependence on evidentiary development at later stages.

⸻

I. Core Principle

State action is inherently public-facing conduct.

Public-facing conduct produces publicly accessible data.

Public data can be used at the plausibility stage.

Therefore:

state action → public data → direct L-layer injection


⸻

II. Canonical Pipeline Integration

Reality / World Level
--------------------------------
state conduct (USE_world)

↓ (recording / visibility)

R (recorded facts)

↓ (plausibility reasoning)

L (legal recognition)

Key shift:

no discovery required for baseline plausibility

when the facts are already public.

⸻

PDIM operates as:

R → L acceleration layer

public records, statements, and narratives
to function as plausibility-supporting inputs
